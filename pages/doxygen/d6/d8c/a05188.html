Detailed Description

Tests for melee/ranged spell crit damage ordering (issue #24976)

The inline melee/ranged spell crit code in CalculateSpellDamageTaken applied SPELLMOD_CRIT_DAMAGE_BONUS BEFORE aura percentage modifiers, causing aura modifiers to amplify the already-talent-modified bonus. The correct order (matching SpellCriticalDamageBonus) is:

  1. Double damage (100% crit bonus for melee/ranged)
  2. Apply aura % modifiers to the full crit value
  3. Extract the bonus portion
  4. Apply SPELLMOD_CRIT_DAMAGE_BONUS to the bonus
  5. Recombine

From the issue's expected blizzlike calculation: 200% * 1.03 = 206% (aura % first) 206% - 100% = 106% (extract bonus) 106% * 140% = 148.4% (talent mod on bonus) 100% + 148.4% = 248.4% (recombine)
