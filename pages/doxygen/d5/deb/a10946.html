This hook is called when Warden evaluates the client's answer to a MEM_CHECK or MPQ_CHECK, right before the answer is compared with the expected bytes.

A script may replace the expected bytes (warden_checks.result) for this session only, for example for a client build whose memory or files legitimately differ from the stock client.

Parameters
sessionContains information about the WorldSession
checkThe warden check being evaluated
expectedReceives the bytes the client must return: check.Length bytes for a MEM_CHECK, 20 (SHA1) for an MPQ_CHECK
Returns
true if expected was filled; the first script returning true wins
